📌 Project Overview
This project features a scalable Selenium automation framework built using the Page Object Model (POM) design pattern. It organizes test logic and page interactions into reusable Java classes, improving maintainability and readability.

✅ Key Highlights:
Developed and automated 35+ test cases covering critical business functionalities:
-User Authentication
-Product Search & Filtering
-Cart & Wishlist Management
-Checkout & Payment
-Customer Engagement (e.g., Sales & Reviews)
Utilized dynamic XPath and CSS selectors for robust, UI-adaptive test scripts.
Implemented detailed logging to support faster debugging and test monitoring.
Configured Allure Reports for rich, visual test result presentation.
Integrated with GitHub and Jenkins to enable CI/CD pipelines and parallel test execution via TestNG.

🛠️ Tech Stack:
Java, Selenium WebDriver, TestNG
Maven, Git, Jenkins
IntelliJ IDEA
Allure for reporting
